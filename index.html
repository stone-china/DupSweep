DupSweep Privacy Policy

Last updated: 17 October 2026 · Publisher: stone.china

In short: DupSweep finds duplicate files on your own device. It does not collect, transmit, sell or share personal data, and it does not connect to any network.

1. Scope

This policy covers the DupSweep Windows application distributed through the Microsoft Store, in all of its language versions, and the data the application processes and stores on your device. It does not cover the Microsoft Store itself, which is operated by Microsoft.

2. Data we do not collect

  • No telemetry, analytics, crash reports or usage statistics.
  • No account, sign-in, name, email address or advertising identifier.
  • No file names, file contents, file hashes or folder names are sent anywhere.
  • No advertising, tracking or analytics SDKs are included.

We receive no data from DupSweep and therefore hold no personal data about you.

3. Data processed on your device

To find duplicates, DupSweep reads the following locally:

  • the folders you add to the scan list, and the names, sizes and timestamps of the files in them;
  • file contents, to compute BLAKE3 hashes and compare candidate files byte for byte.

This processing happens entirely on your device. Scan results are held in memory and are discarded when the application exits. Nothing is uploaded or shared.

4. Data stored on your device

DupSweep keeps its settings in the Windows registry, per user, under HKEY_CURRENT_USER\Software\DupSweep: the list of folders to scan, the size range, the file type filter, the folders excluded from scanning, which copy of a duplicate group to keep, how a click ticks a row, and the chosen interface language.

It also writes a plain-text log under %LOCALAPPDATA%\DupSweep\logs (one file per day). A log may contain file and folder paths, file sizes, scan and deletion results, and error messages, so that a problem can be diagnosed. Logs remain on your device and are never sent to us. You can delete them at any time from Help > Open Log Folder, and uninstalling DupSweep removes its data folder.

5. File deletion

DupSweep deletes only the files you select and confirm. Deletion is carried out by Windows on your device. By default files go to the Recycle Bin, where they can be restored. Permanent deletion is available only through the dedicated Delete Permanently button or menu entry, asks for confirmation twice, and cannot be undone. No information about a deletion leaves your device.

6. Network access

DupSweep does not connect to any network. Its package requests no internet, private-network or location capability; the only capability it declares is runFullTrust, which Windows requires for a desktop application that scans files with the user's own permissions. There is no updater that contacts a server: updates are delivered by the Microsoft Store.

7. Third parties

  • Microsoft Store. Distribution, updates and any payment are handled by Microsoft under the Microsoft Privacy Statement. Microsoft may collect data about Store transactions and downloads independently of DupSweep.
  • BLAKE3. The hash implementation is compiled into the application, runs locally, and collects nothing.

We share no data with anyone, because we receive none.

8. Children

DupSweep collects no personal data from anyone, including children. The application has no accounts, no communication features and no user-generated content.

9. Your rights

Because we hold no personal data about you, there is nothing for us to access, correct, export or erase on your behalf. The data DupSweep stores remains on your device and under your control: you can change it in the application, remove the registry key, or delete the log folder.

If you contact us for support and choose to send a log file, you are sharing that file with us voluntarily. We use it only to answer your request and delete it when the request is closed.

10. Changes to this policy

If this policy changes, the updated version will be published on this page with a new date at the top. Material changes will also be described in the release notes of the affected update.

11. Contact

For privacy questions about DupSweep, use the publisher contact details shown on DupSweep's Microsoft Store product page.

简要说明：DupSweep 只在你自己的设备上查找重复文件。 它不收集、不传输、不出售、不共享任何个人数据，也不连接任何网络。

1. 适用范围

本政策适用于通过 Microsoft Store 发布的 DupSweep Windows 应用程序 （包括所有语言版本），以及该程序在你的设备上处理和存储的数据。本政策不 适用于由 Microsoft 运营的 Microsoft Store 本身。

2. 我们不收集的数据

  • 不收集遥测、分析、崩溃报告或使用统计。
  • 不需要账户、登录、姓名、电子邮件地址或广告标识符。
  • 不会向任何地方发送文件名、文件内容、文件哈希或文件夹名称。
  • 不包含广告、跟踪或分析 SDK。

我们不会从 DupSweep 收到任何数据，因此不持有你的个人数据。

3. 在你的设备上处理的数据

为了查找重复文件，DupSweep 会在本机读取：

  • 你添加到扫描列表的文件夹，以及其中文件的名称、大小和时间戳；
  • 文件内容，用于计算 BLAKE3 哈希并逐字节比较候选文件。

这些处理完全在你的设备上完成。扫描结果只保存在内存中，程序退出时即 丢弃。任何内容都不会被上传或共享。

4. 在你的设备上存储的数据

DupSweep 按用户将设置保存在 Windows 注册表的 HKEY_CURRENT_USER\Software\DupSweep 下：待扫描的文件夹列表、 大小范围、文件类型过滤、排除扫描的文件夹、重复组中保留哪一份、单击列表 时的勾选方式，以及界面语言。

程序还会在 %LOCALAPPDATA%\DupSweep\logs 下写入纯文本日志 （每天一个文件）。日志可能包含文件和文件夹路径、文件大小、扫描与删除结果 以及错误信息，用于诊断问题。日志始终留在你的设备上，绝不会发送给我们。 你可以随时通过“帮助 > 打开日志文件夹”删除它们；卸载 DupSweep 会删除 其数据文件夹。

5. 文件删除

DupSweep 只删除你选择并确认的文件。删除操作由 Windows 在你的设备上 完成。默认情况下文件进入回收站，可以还原。永久删除只能通过专用的“永久删除” 按钮或菜单项执行，并需经过二次确认，且无法撤销。任何删除信息都不会离开你的设备。

6. 网络访问

DupSweep 不连接任何网络。程序包没有申请互联网、专用网络或位置权限； 它声明的唯一能力是 runFullTrust，这是 Windows 对以用户自身 权限扫描文件的桌面应用程序的要求。程序没有会联系服务器的更新器：更新由 Microsoft Store 提供。

7. 第三方

  • Microsoft Store。分发、更新以及可能发生的付款由 Microsoft 依据 Microsoft 隐私声明处理。Microsoft 可能独立于 DupSweep 收集商店交易和下载 相关的数据。
  • BLAKE3。哈希实现直接编译在程序中，在本机运行， 不收集任何数据。

我们不与任何人共享数据，因为我们不会收到任何数据。

8. 儿童

DupSweep 不收集任何人的个人数据，包括儿童。程序没有账户、没有通信功能， 也没有用户生成内容。

9. 你的权利

由于我们不持有你的个人数据，因此没有可供我们代为访问、更正、导出或 删除的数据。DupSweep 存储的数据始终留在你的设备上并由你控制：你可以在 程序中修改它、删除注册表项，或删除日志文件夹。

如果你就支持问题联系我们并选择发送日志文件，即表示你自愿与我们共享该 文件。我们仅将其用于回答你的请求，并在请求处理完毕后删除。

10. 政策变更
